Let’s pick up where you left off — you said induction feels like “dominoes” but recursion feels like “a function calling itself” and you weren’t sure they’re the same thing.

They are two views of the same staircase. Induction climbs up by proof; recursion climbs down by definition.

Exactly — and that “assume P(k)” is the inductive hypothesis. Now watch it become code.

Define factorial recursively: base fact(0)=1, step fact(n)=n·fact(n-1). Proving fact(n)=n! by induction mirrors executing fact by recursion — each reduces the problem by one, trusting the smaller case.

$$fact(n)=\begin{cases}1 & n=0\\ n\cdot fact(n-1) & n>0\end{cases}$$

The same staircase, two directions
