# How Sage teaches

A session with Sage runs as one clean arc: it figures out what you know,
teaches you the material, checks how well it stuck, and re-teaches the parts
that didn't. There are no surprise mid-lesson pop-quizzes — teaching is dense
prose that invites your own questions, and the only formal question rounds are
an opening probe and a closing final quiz.

1. **Probe.** Sage opens with a few questions to gauge how much you already
   know. It uses your answers (and how confident you were) to aim the lesson.
2. **Plan.** It maps out the lesson as the topics to cover, in the order that
   builds on each other.
3. **Teach.** Each topic is taught as clear streaming prose, grounded in your
   study files. Ask questions any time — that's encouraged.
4. **Final quiz.** When the lesson is taught, Sage asks a comprehensive quiz:
   it re-asks the probe questions and adds fresh ones spanning every topic.
5. **Resolve.** Your quiz answers are graded. If anything is missed, Sage
   re-teaches just those points and offers a fresh quiz round. Once it's
   satisfied, the session completes with a summary.

The final quiz never repeats the same question wording — each round is
deduplicated so you only see each question once, however many rounds it takes.
If you answer incorrectly, Sage explains the point again rather than moving on,
so you genuinely learn rather than just passing a test.
